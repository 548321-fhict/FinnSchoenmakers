Cookie policy

Cookies, browser storage, and consent

What this site uses

The site code does not set cookies for analytics, advertising, or social-media tracking. It uses browser local storage (not a cookie) to remember the light/dark theme you select, under the key portfolio-theme. This preference remains in your browser until you clear the site's stored data. You can also use your browser settings to remove or block local storage; the site will still be usable, but may return to its default theme.

The site is hosted by GitHub Pages, which may process technical information or use its own infrastructure technologies to deliver and secure pages. Those are controlled by the host rather than this site's code; see GitHub's privacy statement.

Do you need to consent?

No advertising or analytics consent banner is currently used because this portfolio does not add advertising or analytics trackers. The only site-controlled browser storage is the theme preference described above, which supports the appearance choice you make. Rules can apply to similar storage technologies as well as cookies, and whether a particular implementation qualifies for an exception depends on its purpose and applicable law. If tracking or other non-essential storage is added, the site must be reviewed and any required consent obtained before it is used.

For current Dutch guidance, see the Dutch Data Protection Authority's cookie information.
